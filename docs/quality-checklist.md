# Kvalitetschecklista

## Innehåll

- [ ] Boken är fokuserad och undviker juridiska sidospår.
- [ ] Skillnaden mellan bindande krav, vägledning, policy och god praxis är tydlig.
- [ ] Varje normativt påstående har verifierbar källa.
- [ ] Primärkällor används när de finns.
- [ ] Gällande lydelse och datum kontrolleras inför publicering.
- [ ] Gult presenteras inte som förbjudet.
- [ ] Arkitektens specialistgräns är tydlig.
- [ ] Sektorsspecifika regler framställs som exempel, inte uttömmande katalog.

## Pedagogik

- [ ] Varje kapitel förklarar varför frågan spelar roll för arkitektur.
- [ ] Praktiska scenarier används där de förbättrar förståelsen.
- [ ] Nya juridiska begrepp förklaras vid första användningen.
- [ ] Kapitlen avslutas med viktigaste källorna.

## Markdown/export

- [ ] Endast H1-H3 i manus.
- [ ] Listor och tabeller är canonical Markdown.
- [ ] Kapitelordning matchar exportmetadata.
- [ ] Inga saknade bildreferenser.
- [ ] Omslag innehåller korrekt titel, undertitel och författare.
