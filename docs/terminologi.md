# Terminologi

| Term | Föredragen användning i boken |
|---|---|
| AI | Samlingsbegrepp när ingen mer precis term behövs. |
| AI-system | Används när AI-förordningens systembegrepp är relevant. |
| Generativ AI | AI som genererar exempelvis text, bild, ljud eller kod. |
| Deployer | AI-förordningens rollbegrepp. Förklaras på svenska vid första användningen. |
| Provider | AI-förordningens rollbegrepp. Förklaras på svenska vid första användningen. |
| Högrisk-AI | AI-system klassificerade som high-risk enligt AI-förordningen. |
| RAG | Retrieval-augmented generation. Förklaras kort när det introduceras. |
| Beslutsstöd | AI ger underlag eller rekommendation men människan fattar beslutet. |
| Automatiserat beslut | Beslut där automatiserad behandling har en avgörande roll; juridisk innebörd måste preciseras i respektive regelverk. |
| Sektorsspecifik reglering | Regler som gäller en viss verksamhet, myndighet eller databehandling utöver generella regler. |
